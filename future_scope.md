# Future Scope

The current work is based on simulated side-channel traces and limited cipher families. Future research directions include:

- applying the models to real hardware traces obtained from microcontrollers or FPGA implementations
- extending the framework to AES and other modern block ciphers
- evaluating countermeasures such as masking and hiding techniques
- replacing CNNs with Transformer-based architectures for improved temporal modelling
- integrating reinforcement learning for adaptive key search
- performing full key recovery using energy-guided search methods
